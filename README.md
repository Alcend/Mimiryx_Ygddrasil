# MIMIRYX: Neural Knowledge Network

Mimiryx is a highly visual, futuristic personal knowledge management dashboard. It features a unique volumetric digital organism (The Yggdrasil World Tree) that grows and reacts to your learning progress in real time.

## The Story Behind Mimiryx

The name "MIMIRYX" is inspired by a mix of mythology and Greek influences, centered around the concept of Yggdrasil. 

This project started out of pure frustration. Taking massive amounts of notes in standard Notepad files was exhausting, and organizing them into folders took too many steps. I decided to build my own local note organizer, but as development went on, a simple text app felt too boring. I kept asking myself: *what else can I add to make learning engaging?*

While reading manhwas that featured world trees and gods, I got the idea to build an actual digital World Tree. Now, as I add new topics and notes, the Yggdrasil Tree on the dashboard physically grows new main branches and sub-branches. 

To keep myself motivated (and to see if I was getting lazy), I built out a full analytics suite right next to the tree to monitor my study activity. Over time, fueled by curiosity, I kept expanding the app adding AI assistants to help auto-organize notes, manual backup systems, technical labs, an AI coach, and a sleek futuristic design. It is still a work in progress, constantly evolving as I learn more!

## Key Features

* **Yggdrasil Neural Tree:** A custom built HTML5 Canvas visualization that grows glowing branches representing your active topics, and pulses with energy based on your learning activity.
* **Ambient Auto-Dim UI:** The dashboard intelligently fades into a minimalist screensaver when you are inactive, highlighting your custom wallpapers.
* **Glassmorphism UI:** Stunning, frosted glass components tailored with custom neon accents (Cyan, Purple, Amber, Green).
* **Neural Analytics:** Live tracking of Deep Work sessions, Neural Link density, and system pulse frequency to keep you accountable.
* **Smart Organization:** Notes, Labs, and Topics are categorized with an integrated AI Auto-Clustering workflow.
* **Responsive Architecture:** Built for both ultra-wide monitors and standard laptop displays.

## Tech Stack

* **Framework:** React 18 + Vite
* **Styling:** Tailwind CSS + Custom CSS Variables
* **Icons:** Lucide React
* **Graphics:** Native HTML5 canvas API with dynamic curve math and procedural generation.
* **Routing:** React Router DOM

## Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Alcend/Mimiryx_Ygddrasil.git
   cd Mimiryx_Ygddrasil
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. Open your browser and navigate to `http://localhost:5173/`
